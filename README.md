# ระบบตรวจสอบความหนาท่อ

เว็บแอป Next.js กับ MySQL สำหรับบันทึกเส้นท่อ จุดตรวจ (CML) มุมวัด และประวัติความหนา แล้วคำนวณความหนาออกแบบ อัตราการกัดกร่อน และอายุที่เหลือตาม `SPEC-AIHR-DEV02.md`

หน้าจอใช้โทนจาก `DESIGN-bmw.md`: พื้นขาว ปุ่มสี่เหลี่ยมสีน้ำเงิน แถบหัวเข้ม และตัวอักษรน้ำหนัก 700 กับ 300 ฟอนต์ที่ใช้คือ IBM Plex Sans Thai เพราะตัวอักษรในไฟล์ออกแบบไม่มีอักษรไทย

## เริ่มใช้งาน

แอปต่อ MySQL ที่ `localhost:3306` ฐานข้อมูล `dexon` ตามค่าใน `.env`

```bash
npm install
npm run db:setup
npm run dev
```

เปิด http://localhost:3000

คำสั่ง `npm test` ตรวจสูตรกับตัวอย่างเส้น 6 นิ้วในสเปก โดยไม่ต้องต่อฐานข้อมูล

## สิ่งที่เพิ่มจากสเปก

- `life_status` แยกช่องว่างออกจากอายุไม่จำกัด เพราะตัวเลขที่เป็น null อย่างเดียวแยกสองกรณีนี้ไม่ได้
- คอลัมน์สรุปอัตราและอายุที่เหลือบนตาราง `info` สำหรับหน้าแรกและหัวหน้ารายละเอียด
- หน้าจอเพิ่ม แก้ไข ลบ ทั้งสี่ระดับ พร้อมลบทอดลงทั้งสาย
- วันที่ความหนาจะถึงค่าที่ต้องการ คำนวณจากอายุที่เหลือก่อนปัดคูณ 365.25 วัน แล้วปัดเป็นจำนวนวันเต็ม จุด 180° ได้ 21 ก.พ. 2048 เพราะ 26.137653 ปี คือ 9546.78 วัน สเปกเขียน 22 ก.พ. แต่สูตรเดียวกันนี้ตรงกับ 9 พ.ค. 2044 และ 6 ส.ค. 2028
- ข้อมูลตัวอย่างสามเส้นในสเปก และอีกหนึ่งเส้นขนาด 2.5 นิ้วเพื่อให้เห็นความหนาโครงสร้างที่ว่าง

ความดันออกแบบ 6.999 ความเค้น 137.895 และประสิทธิภาพรอยต่อ 1 ทำให้ความหนาออกแบบของท่อ 6, 3 และ 2 นิ้วตรงกับ 4.186, 2.211 และ 1.500 ตามตารางในสเปก ไฟล์ต้นทางไม่ได้ระบุค่าสามตัวนี้

วันที่ถึงความหนาที่ต้องการคิดจากอายุที่เหลือก่อนปัดคูณ 365.25 วัน ตัวอย่างมุม 90° และ 270° ตรงกับสเปก มุม 180° ได้ 21 ก.พ. 2048 ส่วนตารางในสเปกเขียน 22 ก.พ. 2048
